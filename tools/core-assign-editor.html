Core Assign Editor

Edit the systems, Libretro cores, External emulators, BIOS files and requirements in core.json in your browser, with the file opened and the finished JSON downloaded locally.

Install the finished file as MUOS/info/manifest/core.json. It replaces the bundled file, so begin with the current complete file and keep a backup. A valid file can still refer to a core, launcher, device, BIOS file, or catalogue that is not installed.
