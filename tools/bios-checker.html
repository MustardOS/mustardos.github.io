BIOS Checker

Open the MUOS/bios folder from your SD card to see which BIOS files are present, which are the wrong version, which have the wrong name, and which are missing. Every file is checked in your browser and nothing is uploaded.

Each file is compared against the MD5 checksums in the MustardOS core manifests. Some systems accept several regional BIOS files, so a system only needs the ones its games use, and each name must match exactly, including capital letters. Only systems with a BIOS list in the core manifest are checked, and a system with no BIOS files only needs them if you play it. Folders that no BIOS list names, such as PPSSPP, hold core data and are left unchecked.
