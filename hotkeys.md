# **Handy Hotkeys**

General, frontend-wide hotkeys that work regardless of what you are doing or what is currently loaded.

| Type                   | Control                 |
|:-----------------------|:------------------------|
| Brightness             | MENU + VOLUME UP/DOWN   |
| Screenshot             | L2 + R2 + X             |
| Sleep Suspend / Wake   | Press POWER once        |
| Charging Wake / Boot   | Use the START button    |
| Kiosk Mode Settings    | Press X on Configuration |
| Safe Restart           | L2 + R2 + START         |
| Safe Shutdown          | L2 + R2 + SELECT        |
| Force Quit Process     | R2 + SELECT + B         |
| Modify Content Options | Press X on content      |
| Content Root           | Press START on content  |
| Content Refresh        | Press SELECT on content |
| Shuffle Content        | Press R2 on content     |
| Swap Dpad <> Stick     | L2 + R2 + A             |
| Toggle Stage Overlay   | L2 + R2 + Y             |

{: .note }
> Swap Dpad <> Stick is only for devices without sticks.

## Pickles Hotkeys

Content launched through **[Pickles](/tour/modules/muxretro)** uses in-game **MENU** combinations. Every second
button can be changed from **Pickles Menu > Settings > Input > Hotkeys > Hotkey Buttons**, where **A** opens a list
of buttons to choose from. Choosing a button another shortcut already uses leaves that shortcut unbound, and **X**
restores every default. Fast Forward and Slow Motion can be Disabled, used as a Press toggle, or active while held.

| Type                     | Default Control                    |
|:-------------------------|:-----------------------------------|
| Open Pickles Menu        | Press MENU Once                    |
| Fast Forward             | MENU + R1                          |
| Slow Motion              | MENU + L1                          |
| Quick Save               | MENU + R2                          |
| Quick Load               | MENU + L2                          |
| Pause Content            | MENU + B                           |
| Toggle FPS Counter       | MENU + Y                           |
| Toggle Header Visibility | MENU + X                           |
| Toggle Controller Type   | MENU + A                           |
| Open Manual              | MENU + SELECT                      |
| Quit Content             | MENU + START                       |
| Preview Settings Changes | Hold MENU while Settings is open   |

## Wasabi Hotkeys

Media played through **[Wasabi](/tour/modules/muxmedia)** uses direct buttons for playback and **MENU** combinations
for everything else. Every shortcut can be changed from **Wasabi Menu > Settings > Input > Hotkeys**, where **A** opens
a list of buttons to choose from, and **X** restores every default. Fast Forward and Slow Motion work during local audio playback and can be Disabled,
used as a Press toggle, or active while held from **Wasabi Menu > Settings > Sound**.

| Type                     | Default Control                    |
|:-------------------------|:-----------------------------------|
| Open Wasabi Menu         | Press MENU Once                    |
| Pause / Resume           | A                                  |
| Seek Back 10 Seconds     | DPAD LEFT                          |
| Seek Forward 10 Seconds  | DPAD RIGHT                         |
| Seek Back 60 Seconds     | L1                                 |
| Seek Forward 60 Seconds  | R1                                 |
| Change Repeat            | Y                                  |
| Toggle Shuffle           | X                                  |
| Quick Save Bookmark      | MENU + R2                          |
| Quick Load Bookmark      | MENU + L2                          |
| Toggle Header Visibility | MENU + X                           |
| Fast Forward             | MENU + R1                          |
| Slow Motion              | MENU + L1                          |
| Quit Playback            | MENU + START                       |
| Previous / Next Channel  | DPAD UP / DOWN during live channels |

{: .note }
> Assigning a button that another shortcut already uses leaves that shortcut unbound, so no button does two jobs. Direct buttons
> and **MENU** combinations are kept apart, which is why **X** can toggle shuffle while **MENU + X** toggles the header.

## RetroArch Hotkeys

Content assigned to **RetroArch** uses its own in-game **MENU** combinations.

| Type                    | Control           |
|:------------------------|:------------------|
| RetroArch Menu          | MENU + X          |
| RetroArch Close Content | MENU + START      |
| Fast Forward Toggle     | MENU + R1         |
| Load State              | MENU + L2         |
| Save State              | MENU + R2         |
| Save State Decrement    | MENU + DPAD LEFT  |
| Save State Increment    | MENU + DPAD RIGHT |
| Slow Motion             | MENU + L1         |
| Show FPS Toggle         | MENU + Y          |

{: .note }
> The same **MENU** combo can mean something different depending on which player is running your content.
> **MENU + X**, for example, opens the RetroArch menu but toggles header visibility in Pickles and Wasabi. Check
> **Content Options > Core** if you are ever unsure which one a piece of content is using.

## LED Hotkeys

| Type                | Control                  |
|:--------------------|:-------------------------|
| Change Mode         | MENU + R3                |
| Increase Brightness | MENU + Right Stick Up    |
| Decrease Brightness | MENU + Right Stick Down  |
| Previous Colour     | MENU + Right Stick Left  |
| Next Colour         | MENU + Right Stick Right |

{: .note }
> * These are available on the RG40XX-H, RG40XX-V, RG CubeXX, RG Vita Pro and GCS H36S.
> * The RG40XX-V uses the left stick and **MENU + L3** in place of the right stick and **MENU + R3**.
